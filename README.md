Lamport Logical Clock Simulator
📌 Overview
The Lamport Logical Clock Simulator is an interactive application designed to demonstrate Lamport's Logical Clock algorithm in distributed systems.

It simulates multiple processes, event execution, and message communication to illustrate how logical timestamps are assigned and updated to maintain the causal ordering of events.

🎯 Objectives
Understand Lamport's Logical Clock algorithm.
Simulate multiple processes in a distributed environment.
Visualize internal, send, and receive events.
Demonstrate logical timestamp updates.
Understand the happens-before relationship.
Maintain causal ordering between distributed events.
⚙️ Features
Multiple process simulation.
Logical clock initialization.
Internal event timestamp updates.
Message sending and receiving simulation.
